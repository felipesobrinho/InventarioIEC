    DESENVOLVIMENTO
    ===============
    1. Criar feature branch
       git checkout -b feature/minha-feature
    
    2. Desenvolver com testes
       npm run test:watch
    
    3. Commit & Push
       git push origin feature/minha-feature
    
    4. Criar PR para DEV
       ✅ Workflow test-dev.yml executa
    
    5. Merge para DEV
       Testes passaram? ✅ Merge!

    VALIDAÇÃO (DEV → PROD)
    ======================
    1. Criar PR dev → prod
       ✅ Workflow test-prod.yml executa
       ✅ Verifica: Testes + E2E + Build + Lint
    
    2. Code review & aprovação
    
    3. Merge para PROD
       Tudo validado! ✅

    PRODUÇÃO (PROD → MAIN)
    =====================
    1. Criar PR prod → main
       ✅ Workflow test-main.yml executa
       ✅ Verifica: Cobertura 80% obrigatória
    
    2. Se testes falharem
       🔴 MERGE BLOQUEADO! Corrigir e tentar de novo
    
    3. Se tudo passar
       ✅ Merge seguro! Deploy automático


PRÓXIMOS PASSOS
===============

[ ] 1. Executar testes localmente
       npm test

[ ] 2. Ver cobertura
       npm run test:coverage
       Abrir coverage/lcov-report/index.html

[ ] 3. Adicionar secrets no GitHub
       Settings → Secrets and variables → Actions
       NEXTAUTH_SECRET (obrigatório)

[ ] 4. Começar a escrever testes
       npm run test:watch
       Editar __tests__/

[ ] 5. Aumentar cobertura
       Meta dev: 50%
       Meta prod: 60%
       Meta main: 80%

TROUBLESHOOTING
===============

Jest não roda?
  → npm test -- --passWithNoTests

Playwright não encontra elemento?
  → npm run test:e2e:ui (modo interativo)

Cobertura não atualiza?
  → rm -rf coverage && npm run test:coverage

GitHub Actions não executa?
  → Verificar .github/workflows/ existe
  → Verificar arquivo YAML está correto
